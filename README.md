# Glass Dialer

Android dialer built with Kotlin, Jetpack Compose, and Haze glass effects.

The initial source bundle is stored in `GlassDialer-project.zip`. The first GitHub Actions build expands it into the normal Android Studio project structure, generates the Gradle wrapper, commits those project files to `main`, and builds the debug APK.

Minimum Android version: Android 10 (API 29). The app requests the Android default Phone app role to provide call handling and the in-call interface.
